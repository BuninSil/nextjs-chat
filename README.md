# Fast VPN

> ⚡ **Быстрее нас — только свет.**

Быстрый VPN-клиент для Android по твоей подписке — с отдельным режимом для игроков
**Mobile Legends: Bang Bang** (`com.mobile.legends`) из России.

Делает три вещи:

1. **VPN-клиент со встроенными ядрами sing-box и Xray.** Вставляешь ссылку подписки своего
   VPN-сервиса (ту же, что в Karing, Hiddify или v2rayNG). Приложение само подбирает лучший
   сервер, подключается и, по желанию, сразу запускает игру.
2. **Плашка поверх игры.** Показывает, на каком боевом сервере идёт твой матч: флаг, город,
   пинг, IP. Зелёная, если сервер в России (или в выбранных тобой странах), красная — если
   тебя закинуло за границу. Умеет вибрировать, когда сервер «чужой».
3. **Инструменты для нормальной игры:** тест скорости, игровой режим Wi-Fi без
   энергосбережения, лог соединений игры с выгрузкой в CSV.

Если игра не нужна, при первом запуске выбери **«⚡ Fast VPN»**: останется только
быстрый VPN по подписке, без плашки, игрового режима и прочего про MLBB.
См. [Режим Fast VPN без игры](#режим-fast-vpn-без-игры).

## Быстрый старт

1. **Скачай APK** из [Releases](../../releases/latest) (файл `fast-vpn.apk`) и установи.
   Если телефон спросит — разреши установку из этого источника. Если вылезет окно
   **«Google Play Защита — Рекомендуется проверка приложения»** — это нормально, см.
   [ниже](#окно-google-play-защиты-при-установке).
2. **Открой Fast VPN** и на вопрос «Для чего тебе приложение?» выбери «🎮 + MLBB»
   (если игра не нужна — «⚡ Fast VPN», тогда шаг будет один: подписка). Сверху появится зелёная карточка «Шаг 1 из 3» — просто иди по ней:
   - **Шаг 1 — подписка.** Скопируй ссылку подписки своего VPN и нажми «Вставить ссылку».
   - **Шаг 2 — база стран.** Нажми «Скачать базу» (около 100 МБ, один раз). Без неё плашка
     не сможет показать страну и город сервера.
   - **Шаг 3 — плашка.** Нажми «Открыть разрешение», найди в списке «Fast VPN» и включи
     «Поверх других окон».
3. **Другой VPN (Karing и т.п.) можно не выключать.** Android держит только один VPN, поэтому
   при подключении он спросит разрешение и сам отключит чужой. Сервер подбирается уже после
   этого. Если ссылка подписки без VPN не открывается, приложение обновит её через свой VPN
   на сохранённых серверах — чужой VPN нужен только в самый первый раз.
4. **Нажми большую зелёную кнопку ИГРАТЬ.** Приложение замерит пинг до серверов,
   подключится к лучшему и запустит Mobile Legends.

Всё. Дальше просто играешь, а плашка показывает, где идёт матч.

## Экран «Серверы»

- **Список** — все серверы из подписки. У каждого: флаг, название, протокол, пинг, разброс пинга
  и, если проверялось, скорость (`↓ N Мбит/с`) и реальная страна выхода (`выход 🇷🇺`).
  Неработающие помечены ✖. Выбранный сервер подсвечен зелёным.
- **★** — российский сервер (в игровом режиме они идут первыми).
- **Тап по серверу** — подключиться к нему вручную. Автовыбор при этом выключается,
  включить обратно можно галочкой «Авто» вверху.
- **↻** — перемерить пинг до всех серверов. Работает и без включённого VPN.
- **🌍 Выходы** — узнать, в какой стране каждый сервер на самом деле выходит в интернет.
  Нужен включённый VPN. Результат запоминается до следующего обновления подписки.
- **⚡ По скорости** — замерить скорость через лучшие серверы и включить самый быстрый.
  Нужен включённый VPN.

## Настройки

| Раздел | Что настраивается |
| --- | --- |
| **Режим** | Встроенный VPN / Без VPN / Внешний VPN-клиент — см. [Режимы работы](#режимы-работы). |
| **Встроенный VPN → Автовыбор сервера** | Подбирать лучший сервер при каждом подключении. |
| **Встроенный VPN → Через VPN только игра** | Через туннель идёт только MLBB, остальные приложения — напрямую. Весь канал VPN отдаётся игре. |
| **Встроенный VPN → Матч напрямую** | Трафик самого матча (UDP) идёт мимо VPN — минимально возможный пинг. Работает, только если оператор пропускает игровые серверы без VPN. |
| **Wi-Fi → Игровой режим Wi-Fi** | Не даёт Wi-Fi-модулю засыпать между пакетами (меньше скачков пинга). |
| **Предупреждение** | Вибрация, если матч попал на сервер не из твоего списка стран (по умолчанию `RU`, можно `RU,BY,KZ`). |
| **База стран** | Скачать / импортировать базу DB-IP (`.mmdb`). |
| **Обновления** | Проверять при запуске, проверить сейчас. |
| **Внешний VPN-клиент** | Порт и секрет Clash API — только для режима «Внешний VPN-клиент». |

Всё сохраняется сразу, кнопки «Сохранить» нет. Изменения, которые касаются VPN, применяются
после переподключения: ОТКЛЮЧИТЬ → ИГРАТЬ.

## Режим Fast VPN без игры

Для тех, кому нужен просто быстрый VPN без всего игрового. Выбирается при первом запуске или
в **Настройках → Приложение**; переключать можно в любой момент.

Что остаётся:

- большая кнопка **ПОДКЛЮЧИТЬ / ОТКЛЮЧИТЬ** и карточка текущего сервера;
- подписка, список серверов, автовыбор самого быстрого (по пингу, затем по реальной скорости);
- тест скорости, ускорение Wi-Fi, автообновления.

Что убирается: плашка поверх игры и разрешение на неё, игровой режим, автозапуск MLBB, лог
боёв, режимы «Без VPN» / «Внешний клиент», предупреждение о чужом сервере. База стран в
мастере первого запуска не требуется — нужна только подписка.

## Режимы работы

### 🛡 Встроенный VPN (основной)

Приложение само является VPN-клиентом: подключается к серверам твоей подписки через ядра
sing-box и Xray. Karing и другие клиенты не нужны. Работает где угодно — на Wi-Fi, на мобильном
интернете, в поле. Все функции доступны.

### 📶 Без VPN

Игра идёт напрямую, пинг не меняется. Приложение поднимает **локальный** VPN только для
Mobile Legends — он никуда не шлёт трафик, а лишь подсматривает, к каким серверам подключается
игра, чтобы показать плашку. Подходит, когда VPN не нужен (например, дома на Wi-Fi без блокировок).

### 🔌 Внешний VPN-клиент

Для тех, кто хочет остаться на своём клиенте. Свой VPN приложение не включает, а читает список
соединений у клиента через его **Clash API**. Работает только с клиентами, где этот API можно
включить и узнать порт и секрет: FlClash, Clash Meta for Android и похожие на ядре mihomo.
Karing свой секрет не показывает, поэтому с ним этот режим не работает. Если запущен
**Shizuku**, приложение берёт данные из системной таблицы сокетов — тогда подходит любой клиент.

## Игровой режим

Переключатель **🎮 Игровой режим** на главном экране.

**Включён:**
- плашка с сервером матча поверх игры и лог соединений игры;
- подбор сервера под игру: сначала **серверы с выходом в интернет из России**, потом остальные
  (подробнее в следующем разделе);
- игровой режим Wi-Fi;
- автозапуск MLBB после подключения (если включён тумблер);
- MTU туннеля 1500 — без лишней буферизации мелких игровых пакетов;
- опции «Только игра через VPN» и «Матч напрямую».

**Выключен:**
- просто VPN на весь телефон, без плашки и слежения за игрой (меньше нагрузки);
- сервер подбирается **по скорости**: из лучших по пингу выбирается самый быстрый по загрузке;
- MTU туннеля 9000 — выше пропускная способность.

## Как приложение выбирает сервер

При нажатии ИГРАТЬ / ПОДКЛЮЧИТЬ приложение **не заставляет ждать**:

1. **Сразу подключается к последнему удачному серверу** и за секунду проверяет, что через него
   ходит трафик. Если всё в порядке — готово, обычно это пара секунд.
2. **Полный подбор** запускается, только если он нужен: сервер не отвечает, сменилась сеть
   (Wi-Fi ↔ мобильная), поменялся режим или с прошлого подбора прошло больше 6 часов (и после
   обновления подписки). Идёт он **при уже работающем VPN**, прогресс — в строке статуса, а
   кнопку ОТКЛЮЧИТЬ можно нажать в любой момент.

Как устроен полный подбор (если включён автовыбор):

1. **Пинг до всех серверов напрямую.** Время TCP-рукопожатия до каждого VPN-сервера, в обход
   туннеля — один круг туда-обратно, как в Karing. Три замера на сервер: лучший — пинг,
   разница — разброс.
2. **Первый рабочий сервер** по пингу: через него делается запрос в интернет. Не прошёл — сервер
   помечается ✖ и берётся следующий. Как только найден рабочий — интернет уже есть.
3. **В игровом режиме — проверка страны выхода.** Через сервер спрашиваем у Cloudflare, из какой
   страны пришёл запрос. Берётся первый рабочий сервер **с выходом в России**. Это важно: серверы
   «Обход» / «Мост» часто заходят через Россию, а выходят за границей — игра видит зарубежный адрес
   и кидает на зарубежный сервер (например, в Лондон). Страна выхода проверяется один раз и
   запоминается.
4. **В обычном режиме — замер скорости в фоне.** Через 6 лучших по пингу рабочих серверов
   качается тестовый файл по 2 секунды, побеждает самый быстрый.

Если автовыбор выключен, приложение подключается к выбранному вручную серверу и только
предупреждает, если он не отвечает.

**В игровом режиме сервер выбирается один раз — при подключении, до запуска игры — и дальше
не меняется:** никакого фонового подбора и замера скорости, кнопка «перемерить пинг» в «Серверах»
тоже его не переключает. Смена сервера посреди матча = смена IP = скачок пинга или вылет из катки.

## Плашка поверх игры

Появляется, когда начинается матч (до этого — «жду трафик игры…»).

```
🇷🇺 Москва · 42 ms
185.xx.xx.xx:5521 · 18 КБ/10с
```

- **Боевой сервер** — UDP-соединение игры с наибольшим трафиком за последние 10 секунд
  (DNS, NTP и QUIC не считаются).
- **Страна и город** — по офлайн-базе DB-IP, без интернета.
- **Пинг** — до сервера игры. Через VPN — оценочный, помечается `~`.
- **Цвет:** зелёный — страна из твоего списка (по умолчанию Россия), красный — нет,
  серый — неизвестно.
- **⚠ и вибрация** — если включено предупреждение и сервер «чужой». Один раз на новый сервер.
- Плашку можно **перетаскивать пальцем**, положение запоминается.

## Подписки и протоколы

**Формат подписки:**
- ссылка, которая отдаёт список серверов (обычный текст или base64);
- подписка в формате sing-box (JSON);
- можно вставить вместо ссылки сами серверы — строки `vless://…`, `trojan://…` или base64-блок.

**Протоколы:**

| Протокол | Ядро | Примечание |
| --- | --- | --- |
| VLESS (TCP, Reality, Vision, gRPC, WS, HTTP/2, HTTPUpgrade) | sing-box | |
| VLESS / Trojan с **XHTTP** | Xray | только 64-битные телефоны |
| Trojan | sing-box | |
| VMess | sing-box | |
| Shadowsocks | sing-box | настоящий UDP |
| Hysteria2 | sing-box | настоящий UDP, не проверялся вживую |
| TUIC | sing-box | настоящий UDP, не проверялся вживую |

Не поддерживаются: подписки в формате Clash YAML, WireGuard, транспорт mKCP. Строки-разделители
в подписках («Локации ⬇️») отбрасываются.

**Если панель не отдаёт подписку (HTTP 403).** Приложение по очереди представляется популярными
клиентами (v2rayNG, Happ, Hiddify, Karing, sing-box…) и передаёт идентификатор устройства (HWID),
как это делают сами клиенты. Если панель всё равно отказывает, показывается её ответ — обычно
там причина (например, лимит устройств).

## Скорость и пинг: что реально, а что нет

Честно, без маркетинга:

- **VPN не может быть быстрее твоей сети.** Если без VPN мобильный интернет даёт 25 Мбит/с, через
  VPN будет примерно 20 — шифрование и путь через сервер съедают 10–20%. У всех VPN так.
- **Пинг через VPN = путь до VPN-сервера + путь от него до сервера игры.** Поэтому для MLBB
  лучше всего серверы с выходом в России: серверы игры для РФ стоят в Москве.
- **Для MLBB скорость почти не важна.** Игре нужно меньше 0.1 Мбит/с. Важны пинг и его стабильность.
- **Что приложение делает для минимального пинга:** правильный выбор сервера (см. выше), никакого
  мультиплексирования (оно даёт задержки при потерях), DNS через FakeIP (приложения не ждут
  разрешения имён), серверы с настоящим UDP в приоритете, игровой режим Wi-Fi.
- **Чего нет, потому что это обман:** «ускорителей пакетов», «оптимизации TCP» и «буста сети в
  2 раза» без root не существует.
- **Серверы с TCP-протоколами** (trojan, vless) передают игровой UDP поверх TCP. При потере
  пакета на мобильной сети это даёт скачки пинга. Лучшие для игры протоколы — Hysteria2, TUIC,
  Shadowsocks, если они есть в подписке.

## Тест скорости

Кнопка **⚡ Тест скорости** на главном экране. Меряет через Cloudflare:

- **Пинг и разброс** — 6 замеров (первый, с рукопожатием TLS, отбрасывается);
- **Загрузку** — 4 потока, ~7 секунд;
- **Отдачу** — 4 потока, ~6 секунд.

Если VPN включён — через VPN, иначе напрямую. Так можно сравнить скорость с VPN и без.

## Wi-Fi

На главном экране, когда ты на Wi-Fi, показывается блок с диапазоном, сигналом и пингом до
роутера. Плюс подсказки:

- «Ты на 2.4 ГГц» — если роутер умеет 5 ГГц, переключись: меньше помех и скачков пинга;
- «Слабый сигнал» — подойди ближе к роутеру;
- «До роутера N ms» — если больше ~15 мс, лагает сам Wi-Fi, а не игра.

**Игровой режим Wi-Fi** (в настройках, включён по умолчанию) держит Wi-Fi-модуль в режиме низкой
задержки, пока работает слежение за игрой. Без него модуль засыпает между пакетами, и это даёт
скачки пинга. На Android 14+ система может включать этот режим, только когда приложение на экране.

## Лог соединений

**📋 Лог** — все соединения Mobile Legends: время первого пакета, протокол, адрес и порт, страна
и город, трафик в обе стороны, статус. Боевой сервер отмечен ⚔. Кнопка **CSV** сохраняет лог
в файл, **Очистить** — стирает.

## Обновления

Приложение обновляется само, по релизам этого репозитория на GitHub.

- **В фоне.** Раз в несколько часов проверяет, есть ли новая версия, сам её скачивает и присылает
  уведомление «Обновление Fast VPN скачано — нажми, чтобы установить». Нажал — открывается обычный
  установщик Android на уже скачанный файл. Уже скачанное заново не качается.
- **После обновления** приходит уведомление «Fast VPN обновлён до …», а при открытии приложения
  показывается окно «Обновлено» с тем, что нового.
- **Если пропустил несколько версий** — в окнах «Доступно обновление» и «Обновлено» собраны
  изменения всех версий между установленной и новой, по порядку: «Версия 1.0.86 …, Версия 1.0.84 …».
- **Вручную:** Настройки → «Проверить обновления», или окно при запуске приложения.
- Выключается в Настройках → «Обновлять автоматически». Повторную сборку того же кода
  приложение не предлагает.

## Если что-то сломалось

### Окно «Google Play Защиты» при установке

При установке или обновлении может появиться окно **«Google Play Защита — Рекомендуется
проверка приложения»**. Это не значит, что с приложением что-то не так: Google показывает его
для любого APK, поставленного не из Play Маркета, который он ещё не сканировал. Каждое
обновление — новый файл, поэтому окно может появляться при каждой установке. Убрать его
изнутри приложения нельзя.

Что делать:

1. **Нажать «Установить без проверки»** — приложение просто установится.
2. **Или нажать «Проверить»** — Google просканирует файл и пропустит его; займёт немного времени.
3. **Или выключить окно насовсем:** Play Маркет → аватарка справа сверху → **Play Защита** →
   шестерёнка справа сверху → выключить **«Проверять приложения с помощью Play Защиты»**.
   Минус: Google перестанет проверять вообще все приложения не из Маркета — ставь сторонние
   APK осознанно.

Не нажимай «Не устанавливать» — тогда обновление просто не поставится.

### Другие проблемы

- **Приложение вылетело.** При следующем запуске появится окно «Прошлый запуск упал» с текстом
  ошибки и кнопкой «Скопировать» — скинь этот текст разработчику.
- **VPN не подключается.** Появится окно с причиной и последними строками журнала VPN-ядра.
- **Подписка не загружается.** В ошибке будет ответ панели. Если там про устройства (device /
  HWID / limit) — освободи место под устройство в боте или кабинете своего VPN.
- **Игра не заходит в матч.** Проверь в «Серверах», какой сервер выбран и какая у него страна
  выхода. Попробуй выключить «Матч напрямую», если включал.
- **Переподключения в игре.** Чаще всего это нестабильная мобильная сеть (5G ↔ LTE). Приложение
  не сбрасывает соединения на мелкие изменения сети, но реальную смену сети пережить без
  переподключения нельзя.

## Ограничения

- **Только один VPN.** Android не даёт держать два VPN одновременно. Встроенный VPN и Karing
  вместе не работают.
- **XHTTP — только на 64-битных телефонах.** На 32-битных такие серверы просто не показываются.
- **На какой сервер попадёт матч, решает сама игра.** Приложение может дать игре российский адрес,
  но выбор сервера матча — за MLBB.
- **Адреса серверов MLBB нигде не публикуются.** Приложение узнаёт их из твоих матчей.
- **Пинг на плашке через VPN — оценка**, а не точное значение (без root точнее не измерить).

## Как это устроено внутри

### Встроенный VPN

- **sing-box** (ядро `libbox`, собирается CI из официальных исходников) поднимает туннель
  (`tun`, стек `mixed`) и маршрутизирует трафик. Серверы подписки становятся его outbound'ами,
  выбор — через селектор `proxy`, который приложение переключает по Clash API ядра.
- **Xray** (собирается CI из исходников Xray-core) запускается отдельной программой для серверов
  с XHTTP. На каждый такой сервер — локальный SOCKS-вход, sing-box отдаёт туда трафик сервера.
- **Само приложение исключено из туннеля**, чтобы соединения Xray не уходили в петлю. Свои замеры
  через VPN (тест скорости, проверки серверов) оно делает явно через SOCKS-вход sing-box.
- **DNS — FakeIP:** приложения сразу получают адрес из диапазона `198.18.0.0/15`, домен разрешает
  VPN-сервер. Адреса самих VPN-серверов разрешаются через DNS сети.
- **Монитор сети** сообщает ядру только о реальной смене сети (без VPN), а не о каждом мелком
  изменении мобильной сети — иначе ядро сбрасывало бы соединения.

### Слежение за игрой

- **Встроенный VPN:** соединения игры берутся из Clash API своего ядра (с определением приложения
  по uid).
- **Без VPN:** локальный `VpnService` только для MLBB, пересылка трафика через
  [zdtun](https://github.com/emanuele-f/zdtun) (как в PCAPdroid), статистика по каждому соединению.
- **Внешний клиент:** Clash API клиента или таблица сокетов через Shizuku.
- **Боевой сервер** — UDP-поток с наибольшей активностью за 10 секунд. **Геолокация** — свой
  читатель формата MaxMind DB поверх базы DB-IP City Lite.

## Сборка из исходников

Всё собирается в GitHub Actions:

| Воркфлоу | Что делает | Результат |
| --- | --- | --- |
| `.github/workflows/mlbb-overlay-apk.yml` | Собирает APK на каждый пуш в `mlbb-overlay/**` | релиз `mlbb-v1.0.<номер сборки>` и ветка `apk-builds` |
| `.github/workflows/libbox.yml` | Собирает ядро sing-box (`libbox.aar`, v1.11.4) | ветка `libbox` |
| `.github/workflows/xray.yml` | Собирает Xray-core (v26.9.30) под android/arm64 | ветка `xraybin` |

Готовые ядра лежат в проекте: `mlbb-overlay/app/libs/libbox.aar` и
`mlbb-overlay/app/src/main/jniLibs/arm64-v8a/libxray.so`.

Локально нужны JDK 17 и Android SDK (platform 34, NDK 26.3.11579264, CMake 3.22.1):

```bash
cd mlbb-overlay
echo "sdk.dir=$HOME/Android/Sdk" > local.properties
./gradlew assembleDebug
# -> app/build/outputs/apk/debug/app-debug.apk
```

Установка через adb: `adb install -r app-debug.apk`.

## Структура проекта

| Файл (`mlbb-overlay/app/src/main/…`) | Что делает |
| --- | --- |
| `MainActivity.kt` | Главный экран, мастер первого запуска, ИГРАТЬ, тест скорости |
| `ServersActivity.kt` | Список серверов, ручной выбор, «Выходы», «По скорости» |
| `SettingsActivity.kt` | Настройки |
| `LogActivity.kt` | Лог соединений, экспорт CSV |
| `BoxVpnService.kt` | Встроенный VPN на ядре sing-box (реализация `PlatformInterface`) |
| `BoxConfig.kt` | Конфиг sing-box: туннель, DNS/FakeIP, маршруты, игровой режим |
| `XrayCore.kt` | Запуск Xray для серверов XHTTP, перевод ссылок в конфиг Xray |
| `Subscription.kt` | Загрузка подписки, разбор ссылок всех протоколов |
| `ServerTester.kt` | Пинг серверов, проверка работы, страна выхода, подбор по скорости |
| `MonitorService.kt` | Слежение за игрой (Clash API / Shizuku), плашка |
| `CaptureVpnService.kt`, `cpp/tunbridge.c` | Режим «Без VPN»: локальный VPN на zdtun |
| `ConnTracker.kt` | Журнал соединений, поиск боевого сервера |
| `OverlayController.kt` | Плашка поверх игры |
| `GeoDb.kt`, `MmdbReader.kt` | Офлайн-геолокация по DB-IP |
| `Pinger.kt`, `GameServers.kt` | Пинг до сервера игры |
| `SpeedTest.kt` | Тест скорости через Cloudflare |
| `WifiBoost.kt` | Игровой режим Wi-Fi и диагностика |
| `ClashApi.kt`, `ShizukuSource.kt` | Режим «Внешний VPN-клиент» |
| `Updater.kt`, `UpdateFlow.kt` | Автообновление по GitHub Releases |
| `App.kt` | Перехват падений, журнал ядра |
