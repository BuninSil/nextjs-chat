# Как поменять ссылку на скачивание (и версию/размер) на сайте

Всё живёт в одном файле: **`site/index.html`**. Ничего собирать не надо — это обычный HTML.

---

## 1. Ссылка «Скачать»

Кнопка «Скачать» встречается в файле **два раза** (в шапке и в финальном блоке).
Обе ведут на один и тот же адрес. Меняешь — меняй **оба**.

Ищи в `site/index.html` строки с `class="btn"`. Сейчас там:

```html
<a class="btn" href="https://github.com/BuninSil/nextjs-chat/releases/latest/download/fast-vpn.apk">
```

Замени адрес в `href="..."` на свой. Например:

```html
<!-- свой сервер / CDN -->
<a class="btn" href="https://твой-домен.ру/fast-vpn.apk">

<!-- прямая ссылка на файл в облаке (Яндекс.Диск, VK, свой S3 и т.п.) -->
<a class="btn" href="https://прямая-ссылка-на-apk">
```

**Важно про формат ссылки:**
- Ссылка должна вести **прямо на файл `.apk`** (чтобы по клику он качался), а не на страницу-превью.
- Из **приватного** GitHub-репозитория прямая ссылка `releases/.../fast-vpn.apk` **не работает** без авторизации — скачивание сломается. Поэтому под закрытый код нужен отдельный хостинг файла (свой сервер, S3/CDN, или сервис прямых ссылок).
- Ссылка `releases/latest/download/fast-vpn.apk` хороша тем, что сама указывает на **самую свежую** версию — при переезде постарайся сохранить такой же «вечный» адрес, чтобы не править сайт после каждого релиза.

### Быстрый способ поменять обе разом (терминал)

```bash
cd site
# подставь свой новый адрес вместо NEW_URL
NEW_URL="https://твой-домен.ру/fast-vpn.apk"
sed -i "s#https://github.com/BuninSil/nextjs-chat/releases/latest/download/fast-vpn.apk#${NEW_URL}#g" index.html
grep -n 'class="btn"' index.html   # проверь, что адрес сменился в обеих строках
```

## 2. Версия и размер APK (подпись под кнопкой)

Текст под кнопками задан вручную в **трёх местах**. Ищи `версия 1.0.` и `~38`:

```html
APK · ~38&nbsp;МБ · <b>версия 1.0.182</b><br>бесплатно · без рекламы    <!-- шапка -->
...
<b>версия 1.0.182</b>                                                    <!-- финальный блок -->
...
<span class="ver">BuninSil · v1.0.182</span>                            <!-- футер -->
```

При новом релизе поменяй число версии (`1.0.182` → новое) и, если сильно изменился, размер (`~38 МБ`).
Если лень — можно просто убрать номер версии из текста, тогда обновлять не придётся.

## 3. Применить изменения

### В репозиторий
```bash
cd ..                      # в корень проекта
git add site/
git commit -m "сайт: новая ссылка на скачивание"
git push
```

### На живую страницу (та, что открывается по ссылке-артефакту от Клода)
Живая версия — **отдельная копия**, она НЕ обновляется сама от пуша в git.
Чтобы обновить её, попроси Клода (в новой сессии или здесь) переопубликовать файл `site/index.html`
на тот же адрес артефакта, либо просто открой файл в любом браузере локально — он самодостаточный.

Если сайт выложен куда-то ещё (свой хостинг / GitHub Pages) — просто залей туда обновлённый `index.html`.
