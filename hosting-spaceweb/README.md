# Fast VPN — комплект для SpaceWeb

Компактный backend для бесплатного shared-хостинга SpaceWeb: PHP + MySQL 5.7, без Composer, Node.js, Cloudflare и постоянных процессов.

## Что входит

- Приём диагностических отчётов Android: `/api/report.php`
- Закрытая панель обращений: `/admin/`
- Информация о версии: `/api/version.php`
- Стабильная ссылка загрузки: `/download.php`
- Приём нового APK и атомарная замена старого: `/api/publish.php`
- Установщик, создающий таблицы, конфигурацию, пароль администратора и секрет публикации.

## Важно о бесплатном тарифе

По документации SpaceWeb: 1 ГБ диска, одна MySQL 5.7 БД, PHP 8.x, один сайт. Лимиты CPU/MySQL низкие. Поэтому:
- не загружаем полные мегабайтные логи;
- один отчёт содержит максимум около 9 КБ диагностических строк;
- вложения и скриншоты не принимаются;
- база индексирована, списки обращений выводятся порциями;
- старый APK удаляется после успешной проверки нового;
- не используем email-уведомления.

## Размещение

### 1. Подготовить домен и сайт

1. Привяжи `buninsil-fast-vpn.ru` к аккаунту SpaceWeb.
2. Включи HTTPS/Let's Encrypt и проверь, что сайт открывается по HTTPS.
3. В панели открой настройки сайта и посмотри фактическую папку сайта (обычно `public_html`).
4. Включи PHP 8.2 или новее.

### 2. Создать базу данных

В панели SpaceWeb создай одну базу MySQL. Сохрани:
- имя БД;
- имя пользователя;
- пароль;
- адрес сервера БД (не угадывай localhost, возьми значение из панели).

Не отправляй эти реквизиты в чат и не добавляй их в GitHub.

### 3. Загрузить файлы

В файловом менеджере аккаунта создай рядом с `public_html` каталог `private`.

Содержимое папки `hosting-spaceweb/public/` загрузи в корень сайта (`public_html/`).
Содержимое `hosting-spaceweb/private/` загрузи в `/private/`, НЕ внутрь public_html.

Итог:
```
/home/ACCOUNT/
  private/
    schema.sql
    storage/
  public_html/
    index.html
    .htaccess
    install.php
    api/
    admin/
    releases/
```

Не удаляй существующие файлы сайта без резервной копии. Если сайт уже размещён, сначала объедини папки и замени только те файлы, которые входят в этот комплект.

### 4. Защитить установщик

В каталоге `/private/` создай текстовый файл `setup.key` со случайной строкой не короче 40 символов. Не используй пароль от SpaceWeb. Этот файл не загружается в публичную папку.

Открой `https://buninsil-fast-vpn.ru/install.php`, введи ключ из `setup.key` и реквизиты MySQL. Установщик:
- создаст таблицы;
- создаст `/private/config.php`;
- сгенерирует случайный пароль администратора и секрет публикации APK;
- покажет оба значения один раз.

Сразу сохрани пароль администратора и секрет публикации в менеджер паролей. Секрет публикации позже добавляется в GitHub Actions Secrets как `SPACEWEB_PUBLISH_SECRET`.

После успешной установки:
1. Удали `public_html/install.php`.
2. Удали `/private/setup.key`.
3. Убедись, что `/private/config.php` недоступен по HTTP.
4. Войди в `/admin/` и поменяй пароль администратора, если потребуется.

### 5. Проверить API

Открой:
- `https://buninsil-fast-vpn.ru/api/version.php` — до первой публикации вернёт `available: false`.
- `https://buninsil-fast-vpn.ru/download.php` — сообщит, что APK пока не опубликован.

Отчёт из приложения появится в `/admin/` после того, как новая сборка приложения с сетевой отправкой будет установлена и домен настроен.

## Автоматическая публикация APK из GitHub Actions

Автопубликация включается после того, как SSH/SFTP доступ SpaceWeb реально доступен. В бесплатном тестовом периоде SFTP может быть выключен; SpaceWeb пишет, что SSH включается в панели после тестового периода.

В GitHub → Settings → Secrets and variables → Actions добавь:
- `SPACEWEB_HOST` — сервер из панели SpaceWeb;
- `SPACEWEB_USER` — логин хостинга;
- `SPACEWEB_PASSWORD` — пароль для SFTP;
- `SPACEWEB_FINGERPRINT` — проверенный SHA256 fingerprint SSH-хоста;
- `SPACEWEB_INCOMING_PATH` — абсолютный путь к `/private/storage/incoming/`;
- `SPACEWEB_SITE_URL` — `https://buninsil-fast-vpn.ru`;
- `SPACEWEB_PUBLISH_SECRET` — секрет, который показал установщик.

Не добавляй пароли в файлы репозитория. При публикации официального тега `mlbb-v*` GitHub Actions загрузит APK во временную папку, затем подпишет запрос и вызовет publish API. Сервер проверит SHA-256, заменит текущий APK и удалит предыдущую версию. Если проверка не пройдёт, текущий файл останется нетронутым.

Перед релизом включи SSH в панели SpaceWeb: Инструменты → SSH. В тестовом периоде эта возможность может быть недоступна. Порт SFTP — 22.

Если SSH/SFTP пока недоступен, загрузи APK вручную через файловый менеджер в `/private/storage/incoming/fast-vpn.apk`, затем выполни публикацию из закрытой админки (кнопка появится после настройки секрета). Не используй обычный незашифрованный FTP для передачи паролей и секретов.

## Эксплуатация и лимиты

- APK хранится только в одном экземпляре: `public_html/releases/fast-vpn.apk`.
- Перед заменой проверяется SHA-256 и формат версии.
- Предыдущий APK временно сохраняется только на время транзакции, затем удаляется.
- В базе хранятся только отчёты и статусы. IP пользователей не сохраняются в открытом виде.
- Диагностические файлы не принимаются.
- В админке можно удалять старые отчёты. Для бесплатного тарифа разумно периодически удалять решённые обращения старше 90 дней.
- Сделай резервную копию БД перед первым реальным запуском.

## Ограничения

Это облегчённая система для небольшой группы тестировщиков, а не публичный helpdesk. Если появятся сотни пользователей и частые скачивания APK, бесплатный тариф с лимитом MySQL/CPU будет узким местом. В таком случае сначала переносится backend/хранилище на тариф с большим лимитом, приложение менять почти не придётся.
